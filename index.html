Backup & Restore Database (JSON)

Amankan seluruh database lokal (produk, riwayat penjualan, mutasi stok, pengaturan) ke dalam satu file JSON.

1. Backup Database (Download JSON)

Simpan file backup secara berkala ke flashdisk atau Google Drive Anda. Database tersimpan 100% di browser lokal Anda.

2. Restore Database dari File JSON

Pulihkan data dari komputer lain atau pulihkan kembali setelah pembersihan cache browser.

3. Zona Bahaya: Bersihkan Database

Hapus seluruh data produk dan transaksi untuk memulai toko dari awal. Pastikan Anda sudah mengunduh backup sebelum melakukan ini!
